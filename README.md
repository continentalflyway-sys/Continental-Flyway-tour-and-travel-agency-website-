# Continental Flyway — New Website Starter

Premium navy, white, and gold travel agency website built from scratch with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling
- `app.js` — mobile navigation, flight request form interactions, contact enquiry
- `README.md` — setup notes

## Run locally
Open `index.html` in a modern browser. For a local development server, use VS Code Live Server or run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Before publishing
1. Replace `your-email@example.com` in `index.html` and `app.js` with the business email.
2. Replace the sample location/contact details with verified business details.
3. The flight form is a front-end demo, not a live fare search. To return real fares and book tickets, connect an authorized airline/GDS/flight API and a secure backend.
4. The contact form currently prepares an email via `mailto:`. For reliable submissions, connect a backend or form service.
5. Review image licensing/availability and replace external Unsplash images if needed.
6. Add privacy policy, terms, refund/cancellation information, and any required travel-agent registration details before launch.

## Notes
No API keys or secret credentials are included in this starter.
